## 1. High-Level Architecture

Recovery Manager is a **headless, multi-tenant evidence reconciliation and financial dispute engine**. It connects physical warehouse operations with marketplace accounting by matching channel fee accusations against operational proof generated by the four upstream managers.

## 2. Core Modules & Component Responsibilities

The codebase in `submissions/hayth31/agent/` is structured into clean, decoupled layers:

### 2.1 `core/tenancy.py` — Tenancy Isolation (Rule 1)
- **Responsibility:** Guarantees absolute isolation between organizations (`org_demo_alpha` and `org_demo_bravo`).
- **Mechanisms:**
  - `TenantContext(org_id)` validates all records passing through the matcher.
  - `TenancyViolationError` is raised immediately upon any attempt to join or query cross-tenant data.
  - `secure_asset_token()` generates HMAC-SHA256 signatures for photo references, preventing guessable asset URL attacks.

### 2.2 `core/models.py` — Typed Domain Contracts
- **Responsibility:** Defines strongly typed dataclasses and JSON serialization schemas for:
  - `FeeChargeRecord`
  - `ReceivingRecord` (Dock condition, PO lines, damage states)
  - `PrepRecord` (Polybag, suffocation warning, FNSKU placement, barcode coverage)
  - `PackRecord` (Carton contents, scale weights, dimensions, box seal)
  - `ReturnsRecord` (LPN tracking, returned condition, operator disposition)
  - `ClaimPackage` (Verdict, grounds, evidence chain, human override)

### 2.3 `core/matcher.py` — Cross-Pod Evidence Joiner
- **Responsibility:** Ingests upstream CSV records, verifies tenant ownership, and builds multi-key lookup tables indexed by `unit_id`, `fba_shipment_id`, and `order_id`.
- **Deduplication:** Tracks previously seen charges and prior reimbursement credits to prevent filing duplicate claims.

### 2.4 `core/rules_engine.py` — Authoritative Amazon Rules (Rule 5)
- **Responsibility:** Implements deterministic rule logic based directly on Amazon Seller Central policies:
  - *Inbound Defect Policy:* Verifies prep compliance (`fnsku_label_placement == "flat"`, `original_barcode_covered == "yes"`).
  - *Cubiscan Weight Tier Policy:* Compares charged fulfillment fee against official SKU schedule benchmarks.
  - *Lost Inbound Policy:* Verifies dock receipt of units marked lost by Amazon.
  - *45-Day Customer Return Policy:* Verifies physical warehouse return intake.

### 2.5 `core/claim_builder.py` — Batched AI Claim Synthesis (Rules 2 & 3)
- **Responsibility:** Generates professional dispute letters citing official policy and attached evidence.
- **Batching (Rule 2):** Bundles all claims in a shipment or batch into **one single LLM prompt**.
- **Fail-Open (Rule 3):** If the external Gemini API is rate-limited, unavailable, or lacks credentials, the system automatically falls back to deterministic template generation without dropping records or blocking the pipeline.

### 2.6 `web/app.py` — Evidence Record Dashboard (Face 5)
- **Responsibility:** Interactive Streamlit interface providing:
  - Active tenant selection with forced RLS.
  - KPI overview metrics.
  - Charge & evidence audit inspector.
  - Policy citation expander.
  - Operator override submission and audit log.

## 3. Data Contracts & Schemas

Formal JSON Schemas are stored in `submissions/hayth31/contract/`:
- `fee_reimbursement_report_schema.json`: Input contract for fee charges and adjustments.
- `upstream_evidence_contract.json`: Input contract for Receiving, Prep, Pack, and Returns.
- `authoritative_rules.json`: Catalog of authoritative Amazon FBA policies and dispute rules.
- `claim_output_contract.json`: Output contract for claim decisions and evidence trails.

---

## 4. Key Engineering Invariants

1. **Conservative Decision Making:** If evidence is missing, the verdict is `SILENT`. If ambiguous, the verdict is `UNCERTAIN`. Evidence is never invented.
2. **Zero Commercial Model Overhead:** Runs entirely on free-tier Gemini 2.0 Flash or local offline compute.
3. **Auditability:** Every claim links directly to upstream record IDs, photo paths, operator IDs, and timestamps.
